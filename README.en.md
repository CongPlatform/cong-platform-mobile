# CONG — Operational Builder for NGOs

[Versão em português](./README.md)

**CONG** is a modular platform designed for NGOs, allowing social organizations to create customized operational systems by choosing ready-to-use modules.

The proposal is to work as an **operational builder for NGOs**, helping organizations manage processes such as beneficiaries, volunteers, inventory, donations, scheduling, communication, and reports.

## Objective

To develop an accessible, modular, scalable, and collaborative platform to support the operational management of NGOs.

## Project status

The project is currently in its initial phase of planning, research, prototyping, and architectural definition.

## Main ideas

* Modular platform
* Multi-tenant SaaS
* Incremental development
* Accessible interface for non-technical users
* Open-source and collaborative project proposal
* Possibility of creating modules and templates by the community

## Planned modules

* Beneficiaries
* Volunteers
* Inventory
* Donations
* Schedule
* Reports
* Communication
* Document management

## Planned technologies

The technologies are still being defined, but the project may use:

* React
* Next.js
* TypeScript
* Tailwind CSS
* Node.js
* PostgreSQL
* Supabase
* React Native
