# CONG — Construtor Operacional para ONGs

[English version](./README.en.md)

O **CONG** é uma plataforma modular desenvolvida para ONGs, permitindo que organizações sociais criem sistemas operacionais personalizados por meio da escolha de módulos prontos para uso.

A proposta é funcionar como um **construtor operacional para ONGs**, ajudando as organizações a gerenciar processos como beneficiários, voluntários, estoque, doações, agendamentos, comunicação e relatórios.

## Objetivo

Desenvolver uma plataforma acessível, modular, escalável e colaborativa para apoiar a gestão operacional de ONGs.

## Status do projeto

Atualmente, o projeto está em sua fase inicial de planejamento, pesquisa, prototipação e definição da arquitetura.

## Principais ideias

* Plataforma modular
* SaaS multi-tenant
* Desenvolvimento incremental
* Interface acessível para usuários sem conhecimentos técnicos
* Proposta de projeto open-source e colaborativo
* Possibilidade de criação de módulos e modelos pela comunidade

## Módulos planejados

* Beneficiários
* Voluntários
* Estoque
* Doações
* Agenda
* Relatórios
* Comunicação
* Gestão de documentos

## Tecnologias planejadas

As tecnologias ainda estão sendo definidas, mas o projeto poderá utilizar:

* React
* Next.js
* TypeScript
* Tailwind CSS
* Node.js
* PostgreSQL
* Supabase
* React Native
