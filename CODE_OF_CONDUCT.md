# Código de Conduta — CONG Mobile

[English version below](https://github.com/CongPlatform/cong-platform-mobile?tab=coc-ov-file#code-of-conduct--cong-mobile)

O **CONG Mobile** é o aplicativo móvel da plataforma **CONG — Construtor Operacional para ONGs**, desenvolvido como um projeto colaborativo e open-source, voltado para impacto social e apoio a organizações sociais.

Para manter um ambiente respeitoso, seguro e produtivo, todos os participantes do projeto devem seguir este código de conduta.

## Nosso compromisso

Nos comprometemos a manter um ambiente aberto, acolhedor e respeitoso para todos, independentemente de nível de experiência, formação, idade, aparência, origem, idioma ou área de atuação.

O desenvolvimento do CONG Mobile deve ser um espaço onde estudantes, desenvolvedores, designers, voluntários, ONGs e demais colaboradores possam participar de forma construtiva.

## Comportamentos esperados

São exemplos de comportamentos esperados:

- Tratar outras pessoas com respeito
- Ser paciente com iniciantes
- Fazer críticas de forma construtiva
- Explicar decisões técnicas com clareza
- Aceitar opiniões diferentes
- Colaborar para melhorar o aplicativo
- Manter discussões focadas no projeto
- Reconhecer contribuições de outras pessoas

## Comportamentos não aceitos

Não serão aceitos:

- Ataques pessoais
- Ofensas, humilhações ou provocações
- Comentários preconceituosos ou discriminatórios
- Assédio de qualquer tipo
- Exposição indevida de dados pessoais
- Desrespeito a ONGs, beneficiários, voluntários ou colaboradores
- Uso do projeto para fins maliciosos
- Discussões agressivas ou fora do propósito do projeto

## Responsabilidade dos colaboradores

Todos os colaboradores devem ajudar a manter um ambiente saudável.

Caso encontre um problema, tente agir com respeito e, se necessário, comunique os responsáveis pelo projeto.

## Aplicação

Este código de conduta é aplicado pelos **maintainers responsáveis pelo repositório CONG Mobile**.

Eles são responsáveis por analisar relatos de violações, avaliar cada situação e tomar as medidas necessárias de acordo com a gravidade do caso.

Os maintainers poderão remover comentários, issues, Pull Requests ou contribuições que violem este código de conduta.

Em casos mais graves, uma pessoa poderá ser impedida de participar do projeto.

Para relatar uma violação, entre em contato com os maintainers por meio dos canais oficiais disponíveis no repositório.

## Objetivo

Este código de conduta existe para proteger a comunidade e garantir que o CONG Mobile cresça como parte de um projeto técnico, social e colaborativo.

# Code of Conduct — CONG Mobile

[Versão em português acima](https://github.com/CongPlatform/cong-platform-mobile?tab=coc-ov-file#c%C3%B3digo-de-conduta--cong-mobile)

**CONG Mobile** is the mobile application of **CONG — Operational Builder for NGOs**, developed as a collaborative and open-source project focused on social impact and support for social organizations.

To maintain a respectful, safe, and productive environment, all project participants must follow this code of conduct.

## Our commitment

We are committed to maintaining an open, welcoming, and respectful environment for everyone, regardless of experience level, background, age, appearance, origin, language, or field of work.

The development of CONG Mobile should be a space where students, developers, designers, volunteers, NGOs, and other contributors can participate constructively.

## Expected behavior

Examples of expected behavior include:

- Treating others with respect
- Being patient with beginners
- Giving constructive feedback
- Explaining technical decisions clearly
- Accepting different opinions
- Collaborating to improve the application
- Keeping discussions focused on the project
- Recognizing other people’s contributions

## Unacceptable behavior

The following behaviors are not accepted:

- Personal attacks
- Insults, humiliation, or provocation
- Prejudiced or discriminatory comments
- Harassment of any kind
- Improper exposure of personal data
- Disrespect toward NGOs, beneficiaries, volunteers, or contributors
- Use of the project for malicious purposes
- Aggressive discussions or discussions unrelated to the project’s purpose

## Contributor responsibility

All contributors should help maintain a healthy environment.

If you find a problem, try to act respectfully and, if necessary, contact the project maintainers.

## Enforcement

This code of conduct is enforced by the **maintainers responsible for the CONG Mobile repository**.

They are responsible for reviewing reports of violations, assessing each situation, and taking appropriate action according to its severity.

Maintainers may remove comments, issues, Pull Requests, or contributions that violate this code of conduct.

In more serious cases, a person may be prevented from participating in the project.

To report a violation, contact the maintainers through the official channels available in the repository.

## Purpose

This code of conduct exists to protect the community and ensure that CONG Mobile grows as part of a technical, social, and collaborative project.
